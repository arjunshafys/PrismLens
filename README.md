# PrismLens

PrismLens is a high-performance, real-time image analysis engine supporting multi-data-source ingestion and API-driven output.

PrismLens is built to be simple and practical, focusing on doing one thing well.

**Why PrismLens?**

- PrismLens is a high-performance, real-time
- image analysis engine supporting multi-data-source
- ingestion and API-driven output

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/PrismLens.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure PrismLens, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
